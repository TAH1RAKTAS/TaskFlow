# LinkedIn paylaşım metni

Yeni full-stack projem **TaskFlow**'u tamamladım. 🚀

TaskFlow, kullanıcıların görevlerini yönetebildiği, öncelik ve son tarihe göre planlama yapabildiği, tamamlanan görevleri takip edebildiği ve e-posta hatırlatıcıları oluşturabildiği bir görev yönetimi uygulaması.

Projede kullandığım başlıca teknolojiler:

- ASP.NET Core 10 Web API ve Entity Framework Core
- Microsoft SQL Server
- JWT Authentication ve BCrypt
- React 19, TypeScript ve Vite
- xUnit, Moq ve EF Core InMemory
- Docker Compose ve Serilog

Bu projeyle katmanlı backend geliştirme, kullanıcı bazlı veri izolasyonu, sayfalama/filtreleme, background service, güvenli yapılandırma yönetimi ve full-stack entegrasyon konularında pratik yaptım.
